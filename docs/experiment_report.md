# Хэмжилтийн туршилтын тайлангийн маягт

Маягтын хоосон нүдийг тухайн туршилтын утгаар бөглөж, хэмжээгүй талбарт «хэмжээгүй» гэж бичнэ.

## Дахин давтах нөхцөл

| Бүртгэл | Тухайн туршилтын утга |
|---|---|
| Огноо, гүйцэтгэгч, эх кодын хувилбар | |
| Камер, нягтрал, фокус, калибровкын дүрсний тоо ба пикселийн алдаа | |
| Мэдрэгч, байрлал, өнцөг, бодит тэнхлэгийн зөрүү | |
| Тулгуур багажийн хуваарь, тэг цэг, линзний эхлэл цэгийн тодорхойгүй байдал | |
| Биет, хэмжсэн ирмэгүүд, байрлуулалт, гэрэл, гадаргуу | |
| Жингийн эх үүсвэр, тохиргооны хэш, ангиллын дараалал, гүний алхам | |
| Үйлдлийн систем, процессор, санах ой, тэжээлийн горим, драйвер ба сангууд | |
| Дүрс бичлэгийн хэш, туршилтын дугаарууд, өгөгдөл ба агшны зам | |

## Зай ба хэмжээ

Зай тус бүрд мөрийг хуулж нэмнэ. Зайг метрээр, өргөн ба өндрийг сантиметрээр, хувийн алдааг хувиар бичнэ. Үнэлгээний бүтэн хүснэгтийг хавсаргана.

## Үр дүнг тайлбарлах асуултууд

- Аль зай, аль гадаргуу дээр зөрүү ихэссэн бэ? Шугамын уншилт, биетийн өнцөг, танигчийн хүрээний савлалт тус бүр хэр нөлөөлөв?
- Мэдрэгчтэй горимд хэдэн шинэ хэмжилт орж, хэдэн удаа өмнөх засвар хадгалагдсан бэ? Хүчинтэй хосын дотор горимуудын алдаа хэр зөрөв?
- Аль байрлуулалт, давталтаас өгөгдөл хасагдсан бэ? Амжилттай агшнуудыг дангаар нь сонгосон эсэхээ хэрхэн шалгав?
- Гүний алхам нэмэхэд хурд ба хөдөлж буй биетийн хэмжээсийн тогтвортой байдал хэр өөрчлөгдөв?
- Судалгааны дүгнэлт ямар камер, гадаргуу, орчин, зайн интервалд хамаарах вэ?

Тайланд гурван график, ашигласан хүснэгтүүд, хэмжилтийн төлөөлөх агшин, алдаа гарсан агшин болон эх тохиргоог хавсаргана.
