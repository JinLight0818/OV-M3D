# OV-M3D

**Open-Vocabulary 3D Spatial Measurement (RGB + ToF Fusion)**<br>
*Монокуляр гүн болон ToF мэдрэгчийн нэгдэлд суурилсан дурын объектын 3D хэмжилт, хяналтын систем*

Вебкам руу аяга, утас хоёрыг харуулж, `cup, phone` гэж оруулна. Програм биет бүрд дугаар оноож, камераас биет хүртэлх шулуун зай, харагдах өргөн ба өндөр, хоёр биетийн хоорондох орон зайн зайг харуулна. Өнгөт дүрсийг дангаар нь ашиглах эсвэл ESP32 (мэдрэгч унших микроконтроллер)-т холбосон ToF (гэрлийн нисэлтийн хугацаагаар зай хэмжих мэдрэгч)-ийн заалтаар гүнийг засах боломжтой.

Координатын эх нь камерын оптик төв. $X$ баруун, $Y$ доош, $Z$ урагш чиглэнэ. Хэмжилтийн цэг нь илэрсэн хүрээний төв цацраг дээр, харагдах гадаргуугийн төлөөлөх гүнд оршино. Налуу биет, халхлагдсан ирмэг, сул илрүүлэлтээс шалтгаалж тооцсон өргөн, өндөр нь шугамаар хэмжсэн хэмжээнээс зөрнө. Дэлгэц дээрх хайрцгийн арын ирмэг нь дүрслэлийн зориулалттай. Шалгалтын самбар зөвхөн калибровк хийхэд хэрэгтэй.

## Суулгах ба эхний ажиллуулалт

Зорилтот орчин нь Ubuntu 26.04 LTS (урт хугацааны дэмжлэгтэй систем), Intel Core 5 120U, 16 ГБ санах ой, Intel-ийн нэгдсэн графиктай зөөврийн компьютер. GNOME Wayland (цонхны орчин) дээр ажиллуулах скрипт XWayland (X11 цонх ажиллуулах давхарга)-ийг сонгодог. Командуудыг төслийн үндсээс ажиллуулна.

```bash
bash scripts/setup_ubuntu.sh
source .venv/bin/activate
python -m pytest -q
python -m src.models.export_openvino
bash scripts/run_demo.sh --source 0
```

Суулгагч Python 3.12 орчин үүсгэж, PyTorch (мэдрэлийн сүлжээний сан)-ийн CPU (төв процессор)-ийн хувилбарыг сонгоно. Анхны суулгалт ба жин хөрвүүлэлтэд сүлжээ шаардлагатай. Хөрвүүлэгч YOLO-World-v2-S (текстээр нэрлэсэн биет илрүүлэгч)-ийн `yolov8s-worldv2.pt` болон Depth Anything V2 Metric Indoor Small (дотор орчны гүнийг метрээр таамаглах жижиг загвар)-ийг татна. Ангиллаа `config/default_config.yaml` дотор сонгоод хөрвүүлнэ. `models/` хавтсанд тогтмол үгсийн жагсаалт, ONNX (загвар солилцох хэлбэр), OpenVINO IR (Intel-ийн гүйцэтгэгчийн завсрын дүрслэл)-ийн `.xml` бүтэц ба `.bin` жин гарна. [Илрүүлэгчийн заавар](https://docs.ultralytics.com/models/yolo-world/) · [Метрийн гүний жин](https://huggingface.co/depth-anything/Depth-Anything-V2-Metric-Indoor-Small-hf)

Камер, цуваа порт эсвэл график төхөөрөмжид эрх хүрэлцэхгүй бол дараах тушаалаар хэрэглэгчээ харгалзах бүлэгт нэмээд системээс гарч дахин нэвтэрнэ. `clinfo -l` нь OpenCL (график төхөөрөмжид тооцоолол ажиллуулах орчин)-ийн төхөөрөмжийг жагсаана. Гүний загвар GPU (график процессор) ашиглах боломжгүй үед CPU дээр үргэлжилнэ. [Intel-ийн тохиргоо](https://docs.openvino.ai/2024/get-started/configurations/configurations-intel-gpu.html)

```bash
sudo usermod -aG render,video,dialout "$USER"
clinfo -l
```

Бичлэг ашиглах бол `bash scripts/run_demo.sh --source data/video.mp4` гэж ажиллуулна. Өмнөх бичлэгт одоо залгаатай мэдрэгчийн шинэ заалтыг холихоос сэргийлж дан камераар боловсруулна.

## Дэлгэц ба удирдлага

| Товч | Үйлдэл |
|---|---|
| `M` | Дан камер ба камер–мэдрэгчийн горимыг ээлжлүүлнэ. Хүчинтэй тааруулалт бүрдээгүй эсвэл холбоо тасарсан үед дэлгэцэд «Дан камер» харагдана. |
| `P` | Терминалд ангиллуудыг таслалаар зааглаж оруулна. Жишээ нь `cup, phone, laptop`. |
| `S` | Нэг кадрын зураг, бодит горим, объектын координат, хэмжээ, хосын зайг `data/snapshots/` дотор ижил нэртэй PNG (зураг), JSON (бүтэцтэй бичвэр) файлаар хадгална. |
| `Q` | Дүрс авалт, цуваа порт болон цонхыг хаана. |

Үндсэн дүрсэн дээрх хоёр объектын төв 0.30 м-ээс ойртоход тэдгээрийн холбоос улаан болно. Баруун дээд талд Inferno (гүнийг ялгах өнгөний хуваарь), доод талд BEV (дээрээс харсан зураг), харах өнцөг, гүний төхөөрөмж, боловсруулалтын хурд харагдана.

## Тооцооллын урсгал

1. Гажилт зассан нэг кадрыг илрүүлэгч ба гүний загварт зэрэг өгнө. Суурь тохиргоонд илрүүлэгч CPU дээр, гүн Intel GPU дээр ажиллана. Жинг FP16 (16 битийн хөвөгч таслал)-аар шахаж хадгална.
2. Илрүүлэгчийн тогтмол үгсийг дахин кодлох шаардлагагүй. Шинэ үг өгөхөд `dynamic_fallback: true` сонголтоор PyTorch CPU руу шилжиж, идэвхтэй үгсийн векторыг санах ойд барина. `backend: pytorch` нь шууд энэ горимыг сонгоно. `onnx` ба `openvino` нь хөрвүүлсэн үгсийг ашиглана. ByteTrack (объектыг кадр дамнуулан дугаарлах арга) хүрээ ба дугаарыг буцаана.
3. `depth_every_n_frames: 2` үед гүнийг хоёр кадр тутамд шинэчилнэ. Хурдан хөдөлгөөн хэмжихэд 1 гэж тохируулна. Гүний утгыг хүрээний төвийн өргөн, өндрийн 38 хувиас 30-р хувийн эрэмбээр сонгоно. Параметрийг 50 болговол медиан хэрэглэнэ.
4. Мэдрэгчийн шинэ багцыг тухайн кадртай тулгана. Нэг бүсээр масштаб, 64 бүсээр масштаб ба шилжилтийг олно. Параллакс (хоёр линзний байрлалын зөрүү) болон хавтангийн эргэлтийг тооцно. Хүчингүй багц ирэхэд сүүлчийн тохируулгыг хадгална.
5. 3D (гурван хэмжээст) координат болон харагдах хэмжээг олж, дугаар бүрд EMA (экспоненциал жинтэй дундаж) эсвэл Kalman Filter (төлөвийн эргэлзээг тооцох шүүлтүүр) хэрэглэнэ. Агшинд хадгалсан зайг шүүсэн координатаас тооцдог. [Урсгалын зураг ба багцын бүтэц](docs/03_system_architecture.md) · [Математик үндэслэл](docs/02_methodology_math.md)

## Камер ба фокус

9×6 **дотоод булантай** буюу 10×7 нүдтэй хавтгай самбар ашиглана. Нэг нүдний талыг миллиметрээр хэмжинэ. Доорх жишээнд 25 мм-ийг ашиглав. Самбарыг дүрсний төв, булан, ойр ба хол зайд, зүүн баруун болон дээш доош өөр өөр налуутай харуулж, байрлал бүрд зай авах товч дарна. Дор хаяж найман байрлал авна. `Q` дарахад үр дүн `config/camera_intrinsics.yaml` файлд бичигдэнэ.

```bash
QT_QPA_PLATFORM=xcb python -m src.calibration.camera_calibrate --camera 0 --square-mm 25
```

Зургаас тооцоход `--images 'data/calibration/*.png'` сонголт өгнө. Анхны файл 640×480 дүрсний ойролцоолол тул өөрийн камерын утгаар солих хүртэл хэмжээг урьдчилсан гэж үзнэ. Бичлэгийн үед калибровктой ижил харах өнцөг, фокус, тайралтыг хадгална. `train_focal_px` нь `focal_reference_width` өргөнд дүйцэх жишиг фокус. Утга тогтоогоогүй бол `null` хэвээр үлдээнэ. Фокусыг үнэлгээний сорьцоос тусдаа мэдэгдэж буй зайгаар тааруулна.

## ESP32 холбох ба бэхлэх

3.3 В тэжээл, 3.3 В логик дэмждэг бэлэн мэдрэгчийн хавтан сонгоно. I2C (хоёр утаст өгөгдөл дамжуулах шугам)-д нэг мэдрэгч холбоно. Тэжээлийг салгасан үед утсаа холбоно.

| Мэдрэгчийн шон | ESP32-C3 SuperMini | ESP32 DevKit | Зориулалт |
|---|---|---|---|
| `VIN/3V3` | `3V3` | `3V3` | Хавтангийн 3.3 В оролт |
| `GND` | `GND` | `GND` | Нийтлэг газардуулга |
| `SDA` | `GPIO4` | `GPIO21` | Өгөгдөл |
| `SCL` | `GPIO5` | `GPIO22` | Цаг |

Arduino IDE (микроконтроллерын програм бичих орчин)-д Espressif-ийн `esp32` хавтангийн багцыг суулгана. Сонгосон мэдрэгчдээ тааруулж сангийн менежерээс `VL53L1X` (Pololu-ийн нэг бүст мэдрэгчийн сан) эсвэл `SparkFun VL53L5CX Arduino Library` (8×8 бүст мэдрэгчийн сан)-г суулгана. `firmware/esp32_tof_reader/esp32_tof_reader.ino` файлыг нээнэ. `USE_VL53L5CX` нь 0 бол нэг бүст, 1 бол 64 бүст мэдрэгч ажиллана. C3-д `ESP32C3 Dev Module`, шууд USB холболтод `USB CDC On Boot → Enabled`, энгийн DevKit-д `ESP32 Dev Module` сонгож тохирох порт руу бичнэ. Цуваа дэлгэцээр 921600 бодод нэг мөрийн багц ирж байгааг үзээд дэлгэцээ хааж үндсэн програмыг ажиллуулна. Портыг автоматаар танихгүй бол `serial.port`-д төхөөрөмжийн замыг өгнө. [Нэг бүст мэдрэгчийн сан](https://github.com/pololu/vl53l1x-arduino) · [Олон бүст мэдрэгчийн сан](https://github.com/sparkfun/SparkFun_VL53L5CX_Arduino_Library)

OpenSCAD (параметрт биет загварчлах хэрэгсэл)-д `hardware/sensor_mount.scad` файлыг нээнэ. Дэлгэцийн зузаан, зөөлөвчний зай, хавтангийн өргөн, шурагны төв хоорондын зайг өөрийн эд ангид тааруулна. Хавчаарын ирмэг дэлгэцийн хүрээнд тулж, камерын харах талбай чөлөөтэй байна. Хоёр линзийг урагш зэрэгцүүлээд төв хоорондын баруун, доош чиглэлийн зөрүүг метрээр хэмжиж `fusion.dx_m`, `fusion.dy_m`-д оруулна. Анхны 25 мм нь жишээ утга. Хэвлэх файлыг дараах тушаалаар гаргана.

```bash
sudo apt install openscad
openscad -o /tmp/sensor_mount.stl hardware/sensor_mount.scad
```

## Өгөгдөл ба баталгаажуулалт

```bash
python -m pytest -q
python -m experiments.evaluate_results --synthetic
```

Хиймэл жишээ `results/synthetic/` дотор тэмдэглэгээтэй гурван график ба алдааны хүснэгт гаргана. Бодит туршилтад `S` товчоор агшин авч, доорх тушаалаар файл сонгоно. Програм объектын дугаар, байрлуулалтын нэр, шугамаар хэмжсэн зай ба хэмжээг асууна. Хурдны харьцуулалтад дор хаяж 70 кадртай турших бичлэгээ `data/benchmark.mp4` нэрээр байрлуулна.

```bash
read -rp 'Хадгалсан агшны JSON файлын замыг оруулна уу. ' snapshot
python -m experiments.collect_dataset "$snapshot"
python -m experiments.benchmark_runtime --video data/benchmark.mp4
python -m experiments.evaluate_results
```

`data/measurements.csv` ба `data/benchmark.csv` хүснэгтэд бодит хэмжилт нэмэгдэнэ. Зайг метрээр, өргөн өндрийг сантиметрээр үнэлнэ. MAE (дундаж үнэмлэхүй алдаа), RMSE (дундаж квадрат алдааны язгуур), MAPE (хувиар илэрхийлсэн дундаж үнэмлэхүй алдаа) ба хурдны график `results/` дотор гарна. [Туршилтын журам](docs/04_experiment_protocol.md) · [Тайлангийн маягт](docs/experiment_report.md)
