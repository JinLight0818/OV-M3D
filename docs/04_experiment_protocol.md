# Хэмжилтийн туршилтыг давтан хийх журам

Дан камер ба ToF (гэрлийн нисэлтийн хугацаагаар зай хэмжигч) мэдрэгчтэй горимыг **ижил байрлуулалт дээр хослуулж** хэмжинэ. Байрлуулалт бүрд ямар зай, ямар хоёр ирмэг хэмжихээ эхэлж тогтооно. Камерын линзээс биетийн харагдах гадаргуугийн төв хүртэлх шулуун зайг метрээр, харагдах урд талын өргөн, өндрийг сантиметрээр бүртгэнэ. Тэнхлэг дагасан гүн $Z$ ба налуу зай $\sqrt{X^2+Y^2+Z^2}$ дүрсний зах руу ялгаатай болдог. `distance_m` баганын лавлагааг хоёр дахь тодорхойлолтоор хэмжинэ.

## Зай ба хэмжээс

1. Камерыг бэхэлж дотоод параметрийг ажлын нягтрал, фокус дээр тохируулна. Мэдрэгчийн линзний байрлал, эргэлт, харах өнцөг ба нэгжийг шалгана. Ашигласан шугамын хуваарь, тэг цэгийн зөрүү, линзний төвийг тогтоосон аргаа тайланд бичнэ.
2. Төвөөс хэмжсэн шулуун зайг 0.50, 1.00, 1.50, 2.00, 2.50, 3.00, 3.50 м болгон долоон түвшин үүсгэнэ. Шулуун өнцөгтэй хайрцаг, аяга, утас зэрэг биетийг сонгож өргөн, өндөр ба хэмжсэн ирмэгийг тэмдэглэнэ. Нүүрийг камерын дүрсний хавтгайтай зэрэгцүүлж, гадаргуугийн төвийг онилно. Холын түвшинд мэдрэгч хүрэхгүй бол хүлээн авсан төлөв, хүчинтэй хэмжилтийн хувийг тусад нь бүртгэнэ.
3. Эхлээд төвд, дараа нь харах талбайн хоёр захад хэмжинэ. Хананаас өөр өөр зайтай байрлуулаад гэрэл, гэрэлтэх өнцөг, хар ба гялгар гадаргуугийн нөхцөлийг бичнэ. Нэг төрлийн хананы өмнө олон бүс нь ижил гүнтэй байвал шугаман тохируулгын налалт тодорхойлогдохгүй. Олон бүсийн тохируулгыг шалгахдаа дор хаяж хоёр ялгаатай гүний хавтгай оруулна.
4. Байрлал бүрд биетээ авч дахин байрлуулан **таван бие даасан давталт** хийнэ. Давталт бүрийн хоёр горимд байрлал, гэрэл, камерын фокусыг тогтвортой байлгана. Шүүлтүүр тогтворжтол урьдчилан сонгосон ижил тооны кадр хүлээнэ. Хоёр горимын дарааллыг ээлжлүүлнэ. Шууд залгаа таван кадрыг таван бие даасан давталт гэж тооцвол хэлбэлзлийг дутуу үнэлнэ.
5. M товчоор горимоо сонгон дэлгэцэд идэвхтэй байгаа горим, мэдрэгчийн төлөвийг шалгана. S товчоор агшин ба хэмжилтийг хадгалаад зураг дээрх биетийн дугаарыг сонгоно. `scene` талбарт нэг хосод ижил, дараагийн давталтад өөр тэмдэглэгээ өгнө. Танигдаагүй, шүүлтүүрт хасагдсан болон дан камер руу шилжсэн оролдлогын тоог тайланд шалтгаантай нь бичнэ. Хоёр горимд амжилттай байсан хосуудын тоог тусад нь гаргана.

Доорх жишээнд агшны зам, дугаар ба гурван тулгуур утгыг тухайн хэмжилтийнхээр солино. Аргументгүй үлдээсэн хэмжээсийг програм асууна. Анхдагч хүснэгт нь `data/measurements.csv` бөгөөд ижил агшин, ижил биетийн дугаарт хоёр дахь мөр нэмэхэд өмнөх мөрөө хадгална.

```bash
python -m experiments.collect_dataset data/snapshots/агшин.json \
  --track-id 1 --scene төв_100_давталт1 \
  --distance-m 1.002 --width-cm 8.15 --height-cm 12.10
```

Хоёр биетийн хоорондох зайг давхар шалгахдаа хоёуланг нэг агшинд оруулж, харагдах гадаргуугийн төвүүдийн хоорондох шулуун зайг шугамаар хэмжинэ. Агшны `xyz_m` хоёр векторын ялгаврын урттай тулгана. Налуу, муруй, халхлагдсан биетийн бодит бүх хэмжээ ба нэг проекцын харагдах хэмжээг тус тус тэмдэглэнэ.

## Тооцоолох хурд

PyTorch (нейрон сүлжээ ажиллуулах сан), ONNX Runtime (солилцооны загвар ажиллуулах хөдөлгүүр), OpenVINO (Intel төхөөрөмжид зориулсан тооцооллын сан) гуравт нэг видео, ижил жин, ижил ангиллууд, ижил геометр хувиргалт ба хүрээний босго хэрэглэнэ. CPU (төв процессор) нь танигчийг ажиллуулна. OpenVINO горимд гүний загвар GPU (график процессор) дээр эхэлнэ. Хүснэгтийн `depth_device` бодитоор ашигласан төхөөрөмжийг заана.

1. Жин ба хөрвүүлсэн загвар бэлэн болсны дараа ажлын камераар авсан, биет үзэгдэх бодит бичлэг сонгоно. Анхдагч тохиргоонд 70-аас доошгүй уншигдах кадр хэрэгтэй. Ачааллын төлөв, тэжээлийн горим, өрөөний хэм, дүрсний хэмжээ, сангийн хувилбаруудыг тайланд тэмдэглэнэ.
2. Хөдөлгүүр бүр тусдаа үйл явцад эхэлж, ижил эхний 10 кадраар хална. Дараагийн 60 кадрын нэг бүрд танигч, гүний загварыг зэрэг эхлүүлж, **хоёул дуусах** хүртэл хэмжинэ. Үүнд дүрсний хэмжээ өөрчлөх, танилт, мөрдөлт, гүн буцаах хугацаа орно. Видео тайлах, загвар ачаалах, дэлгэц зурах хугацаа энэ интервалын гадна байна. Дэлгэц дээр ажигласан нийт хурдыг тусдаа тэмдэглэнэ.
3. Эхний цувралд гүнийг кадр бүрд бодно. Дараагийн цувралд алхмыг 2 болгоно. Ижил цувралыг наад зах нь гурван удаа давтаж, хөдөлгүүрийн дарааллыг сэлгэнэ. Туршилт бүрийн дугаар, видеоны болон тохиргооны SHA-256 (агуулгын хяналтын хэш) хүснэгтэд үлдэнэ. Ижил нөхцөлтэй давталтуудын голчийг тайланд оруулна.

```bash
python -m experiments.benchmark_runtime --video data/benchmark.mp4 --warmup 10 --frames 60 --depth-every 1
python -m experiments.benchmark_runtime --video data/benchmark.mp4 --warmup 10 --frames 60 \
  --depth-every 2 --backends openvino pytorch onnx
```

FPS (секундэд боловсруулсан кадр) нь хэмжсэн кадрын тоог тэдгээрийн боловсруулалтын нийт хугацаанд хуваасан утга. Дундаж хоцролт ба 95-р хувьт хоцролтыг миллисекундээр бичнэ. 95-р хувьт утга нь удаан кадруудын нөлөөг харуулна. Мэдрэгчгүй, файл дутуу, төхөөрөмж шилжсэн үеийн үр дүнг бодит төхөөрөмж, бодит төлөвөөр нь тайлбарлана.

## Үнэлгээ ба гаралт

$g_i>0$ нь шугамын лавлагаа, $p_i$ нь системийн утга, $e_i=p_i-g_i$ нь тэмдэгтэй алдаа. MAE (дундаж үнэмлэхүй алдаа), RMSE (дундаж квадрат алдааны язгуур), MAPE (дундаж үнэмлэхүй хувийн алдаа) гурвыг горим, хэмжигдэхүүн тус бүрд тооцно.

$$
\mathrm{MAE}=\frac{1}{n}\sum_i |e_i|,\qquad
\mathrm{RMSE}=\sqrt{\frac{1}{n}\sum_i e_i^2},\qquad
\mathrm{MAPE}=\frac{100}{n}\sum_i\frac{|e_i|}{g_i}.
$$

```bash
python -m experiments.evaluate_results
python -m experiments.evaluate_results --synthetic
```

`results/metrics.csv` нь ажиглалтын тоо, нэгж, гурван алдааг агуулна. `distance_accuracy.png` файлд цэг бүр нэг ажиглалт, тасархай шулуун нь тооцоо ба лавлагаа тэнцэх байрлалыг заана. `size_accuracy.png` файлд өргөн ба өндрийн MAE-г харьцуулна. `speed_comparison.png` нь хамгийн сүүлд бүртгэсэн нэг туршилтын хурд ба 95-р хувьт хоцролтыг харуулна. Өмнөх цувралыг `--run-id` сонголтоор дугаарыг нь өгч дүрсэлнэ. Нийлбэр алдаанд аль нөхцөл олон орсон нь нөлөөлөх тул нөхцөл бүрийн түүврийн тоог тайланд бичиж, тэнцүү бүрэлдэхүүнтэй хосуудыг харьцуулна.

Хоёр хүснэгт хоосон эсвэл `--synthetic` сонгосон үед тогтмол үртэй санамсаргүй үүсгүүрээр жишээ өгөгдөл бэлдэж, дүрс бүрийг «ХИЙМЭЛ ӨГӨГДӨЛ» гэж тэмдэглэн `results/synthetic/` хавтсанд хадгална. Хурдны хиймэл тоонууд нь графикийн ажиллагааг шалгах зориулалттай. Бодит оролтын зөвхөн нэг хүснэгт ирвэл нөгөө графикт хэмжилт бүртгэгдээгүйг бичнэ.
